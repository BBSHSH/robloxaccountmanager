# Roblox Local Account Launcher

複数のRobloxアカウントを、**選択した既存のChromeプロファイル**で開くローカル専用ランチャーです。

## 安全設計

- パスワードを入力・保存・送信しません。
- `.ROBLOSECURITY` Cookieを読んだり書き換えたりしません。
- 外部サーバーへの通信機能はありません。
- Googleログインを含む既存Chromeプロファイルを、そのまま使います。
- 初回ログインは起動したChrome内の公式Robloxページで、利用者本人が行います。
- アプリが保存するのは、表示名・任意のRobloxユーザー名・メモ・Chrome実行ファイルの場所だけです。

Chromeのプロファイルデータ（ログイン状態を含む）はOSのアプリデータフォルダにChrome自身が管理します。リポジトリやこのアプリはCookieの値にアクセスしません。

## 起動

Node.js 20以上を用意して実行します。

```powershell
npm install
npm start
```

1. Chrome側で、RobloxアカウントごとにChromeプロファイルを作成します。Googleログインを使いたい場合は、そのChromeプロファイルへ自分でログインします。
2. **アカウントを追加** で、表示名と対応するChromeプロファイルを登録します。
3. **Chromeで開く** を押します。
4. 初回だけ、そのChromeウィンドウで公式Robloxに手動ログインします。
5. 次回からは同じカードを開くだけで、選択したChromeプロファイルが起動します。

## 開発チェック

```powershell
npm run check
```

## 注意

これはアカウント切替を補助するローカルランチャーです。Robloxの規約、ゲームごとのルール、アカウント利用条件に従って使用してください。
