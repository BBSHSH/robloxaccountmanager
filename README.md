# Roblox Local Account Manager

複数のRobloxアカウントをローカルで管理するElectronアプリです。

## 機能

- アカウント一覧・ユーザー名・メモを管理
- `.ROBLOSECURITY` をWindows DPAPIで暗号化してローカル保存
- 公式Roblox APIでログイン状態・表示名・アバターを確認
- アカウントごとの独立ブラウザセッションを開く
- Cookie登録済みアカウントをまとめて開く
- アカウント別または全アカウントで指定ゲームを開く

## セキュリティ設計

- Cookieの平文はディスクへ保存しません。
- CookieはWindows DPAPIで暗号化され、そのWindowsユーザーのPC上でのみ復号できます。
- Cookieは画面へ再表示・ログ出力・Git管理しません。
- 外部の管理用サーバー・分析・同期機能はありません。
- 通信先はログイン確認・プロフィール表示・ゲームページを提供する公式`roblox.com`ドメインだけです。

Cookieを登録する前に、ソースコードを確認し、自己責任で使用してください。

## 起動

Node.js 20以上を用意して実行します。

```powershell
npm install
npm start
```

1. **アカウントを追加** で表示名を登録します。
2. そのカードの **Cookieを登録** から、自分で管理するCookieを登録します。
3. **確認** で公式Roblox APIに対してログイン状態を検証します。
4. **ホームを開く** またはゲームIDを入力して **ゲームを開く** を使います。

## 開発チェック

```powershell
npm run check
npm audit
```

## 注意

これはアカウント切替を補助するローカルツールです。Robloxの規約、ゲームごとのルール、アカウント利用条件に従って使用してください。
